# 🚀 درس تحلیل و طراحی سیستم‌ها (Systems Analysis and Design)

&gt; **مدرس:** محمد علی رسول زاده

&gt; **ترم درسی:** پائیز 1405

به ریپازیتوری رسمی درس تحلیل و طراحی سیستم‌ها خوش آمدید!

در این دوره، شما مفاهیم مهندسی سیستم، متدولوژی‌های توسعه (Agile/SDLC)، مدیریت پروژه و مدلسازی نرم‌افزار را در قالب یک **پروژه فردی عملیاتی و مستمر در GitHub** فرامی‌گیرید.

---

## 🎯 ساختار پروژه فردی ترم

هر دانشجو باید **یک سیستم اطلاعاتی واقعی** را از لیست موضوعات پیشنهادی زیر انتخاب کند (یا موضوع اختصاصی خود را با تایید استاد ثبت کند). در طول ترم، با تدریس هر فصل از کتاب، شما باید تحویلی‌های (Deliverables) مربوط به آن فصل را روی پروژه خود اعمال کرده و در ریپازیتوری شخصی خود **Commit** کنید.

### 📌 قوانین و الزامات پروژه:
1. **انفرادی بودن:** هر دانشجو مسئول تحلیل و طراحی کامل سیستم خود است.
2. **یکتایی موضوع:** موضوع انتخاب‌شده نباید با سایر دانشجویان تکراری باشد (ثبت اولویت‌ها در ارسال پیام).
3. **مستندسازی در Markdown:** تمام اسناد و گزارش‌ها باید در قالب فایل‌های `.md` مرتب و اصولی در ریپازیتوری شما قرار گیرند.
4. **تداوم Commitها:** تاریخ و پیوستگی Commitهای شما نشان‌دهنده نظم در پیشبرد هفتگی پروژه است.

## 📅 نقشه راه هفتگی تحویلی‌های پروژه (Weekly Commit Milestones)

| هفته | موضوع فصل کتاب | تحویلی پروژه در GitHub (Git Commit Milestone) |
| :--- | :--- | :--- |
| **هفته ۱** | محیط توسعه و SDLC | ساخت ریپازیتوری شخصی، ایجاد `README.md` و ثبت موضوع انتخابی سیستم |
| **هفته ۲** | منابع تامین نرم‌افزار | تحلیل استراتژی تامین نرم‌افزار (Make vs Buy / SaaS / COTS / Outsourcing) + تدوین اولیه سند RFP |
| **هفته ۳** | مدیریت پروژه (Azure/Git) | شکست ساختار کار (WBS)، ایجاد بورد کانبان (Kanban Board) و تعریف Product Backlog |
| **هفته ۴** | انتخاب پروژه و استراتژی | تحلیل همراستایی استراتژیک سیستم و ماتریس‌های اولیه برنامه‌ریزی (ISP) |
| **هفته ۵** | امکان‌سنجی و BPP | تدوین سند منشور پروژه (Project Charter)، بیانیه محدوده (PSS) و جدول امکان‌سنجی مالی (NPV/ROI) و فنی |
| **هفته ۶** | استخراج نیازمندی‌ها | تدوین سند نیازمندی‌های وظیفه‌ای و غیروظیفه‌ای + نوشتن داستان‌های کاربر (User Stories) |
| **هفته ۷** | **آزمون میانترم** | **جمع‌بندی فاز برنامه‌ریزی و تعاریف اولیه** |
| **هفته ۸** | مدلسازی فرآیندها | رسم نمودار جریان داده (DFD Context &amp; Level-0) یا Use Case Diagram همراه با Narratives |
| **هفته ۹** | مدلسازی داده‌ها | رسم نمودار مفهومی داده‌ها (ER-Diagram) شامل موجودیت‌ها، صفت‌ها و روابط |
| **هفته ۱۰** | طراحی دیتابیس و SQL | تبدیل ERD به جداول منطقی نرمال‌شده (3NF) + اسکریپت‌های فیزیکی SQL (`CREATE TABLE`) |
| **هفته ۱۱** | طراحی UI/UX | طراحی Wireframeها و Mockupهای اولیه فرم‌ها و گزارش‌های اصلی سیستم (با Figma/Visio) |
| **هفته ۱۲** | **تحویل نهایی و ارائه** | **ارائه کامل سند جامع تحلیل و طراحی سیستم (Presentation)** |

## 💡 لیست موضوعات پیشنهادی برای پروژه فردی (Select One)

دانشجویان می‌توانند یکی از سیستم‌های زیر را انتخاب نمایند یا یک سامانه B2B/B2C واقعی جدید پیشنهاد دهند:

### 🏢 بخش ۱: سیستم‌های سازمانی و خدماتی (Enterprise &amp; B2B)
1. **سامانه جامع مدیریت و پایش ناوگان رباتیک (Robotics Fleet Management)**
2. **سیستم اتوماسیون و نوبت‌دهی هوشمند بیمارستانی (Hospital Management System)**
3. **سامانه یکپارچه مدیریت انبار و زنجیره تامین (Supply Chain &amp; WMS)**
4. **سیستم مدیریت هوشمند پارکینگ‌های طبقاتی با تشخیص پلاک (Smart Parking System)**
5. **سامانه مدیریت ارزیابی عملکرد و حقوق و دستمزد پرسنل (HR &amp; Payroll System)**

### 🌐 بخش ۲: پلتفرم‌های ابری و آنلاین (B2C &amp; E-Commerce)
6. **پلتفرم تجارت الکترونیک تخصصی و فروشگاه آنلاین (E-Commerce WebStore)**
7. **سامانه هوشمند تاکسی اینترنتی و مدیریت سفر (Ride-Hailing Platform)**
8. **پلتفرم آموزش آنلاین و مدیریت یادگیری (Learning Management System - LMS)**
9. **سامانه رزرو آنلاین بلیط سفر و تورهای گردشگری (Travel &amp; Ticketing System)**
10. **پلتفرم صرافی دیجیتال و مدیریت کیف پول الکترونیک (Crypto/Fintech App)**

### 🤖 بخش ۳: سیستم‌های هوشمند و اینترنت اشیاء (IoT &amp; AI)
11. **سامانه پایش هوشمند گلخانه‌ها و کشاورزی دقیق (Smart Agriculture IoT)**
12. **سیستم مدیریت و تحلیل هوشمند داده‌های مشتریان (AI-Powered CRM)**

```text
│   └── 04-software-sourcing.md # تحلیل خرید/ساخت و RFP
│
├── diagrams/
│   ├── dfd-level0.png          # نمودارهای فرآیندی
│   ├── er-diagram.png          # نمودار دیتابیس

│
├── database/
│   └── schema.sql              # اسکریپت‌های ساخت دیتابیس
│
└── wireframes/
    └── ui-mockups.pdf          # طرح‌های اولیه فرم‌ها و گزارش‌ها

```
